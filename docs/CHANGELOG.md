# CLIQ Changelog

All notable changes to the CLIQ platform are recorded in this file.

## [1.0.0] - 2026-10-30
### Added
- Initial architectural release of CLIQ — Money Made Simple. In Your Language.
- Core design system: Cinematic dark background (#020B12), Neon Cyan (#00E5E5), Turquoise (#00F5C8), and Emerald (#00D69B).
- 15 functional application screens.
- Deterministic Reward Optimization Engine using Python `Decimal` math.
- Document Intelligence pipeline with PyMuPDF and staged review workflow.
- Multilingual Language Intelligence supporting English, Hindi, and Kannada.
- Financial Health & Spending Analytics engines.
- Comprehensive security architecture: IDOR checks, JWT auth, rate limiting, and RLS policies.
- Full automated test suite across unit, integration, and security layers.
